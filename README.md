# 捷匠PDR — 參考價目與線上試算（demo）

捷匠PDR 免烤漆凹痕修復的價目說明頁面：估價流程、價格三要素解說、
互動式參考價試算器、預約流程與常見問題。單一 HTML 檔，零依賴。

## 預覽

啟用 GitHub Pages（Settings → Pages → Deploy from branch → main / root）
後即可在 `https://<帳號>.github.io/jiejiang-pdr/` 開啟。

## 注意事項

- 試算器內的基礎價、尺寸係數、加成百分比皆為**示範費率**，正式上線前請換成實際定價。
- 頁尾聯繫資訊（電話 / LINE / 營業時間）目前為佔位文字，請填入真實資料。
- 本頁文案與視覺為原創設計。
